# Salt

A night drive along a coast that is not on any map.

The city builds itself when you arrive. There is a radio with four stations. Somewhere past the last bridge, if you stop fighting the wheel, the road changes.

[Play it](https://abdulla-alhosani.github.io/salt/)

A and D steer. W drives. S eases off. Q and E tune the radio. On a phone, use the buttons.
